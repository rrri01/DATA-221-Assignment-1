# DATA-221-Assignment-1
Jan 30 2026

The first file, "question 1.py" will multiply consecutive integers, starting at 1, until the total product becomes greater than the threshold.
Then it will print out the final product, and the value that caused the product to exceed the threshold

The second, "question 2.py" will created a nested dictionary from a list of strings.
It takes each string in a list, and creates a dictionary inside of our main dictionary for each string, containing the length and parity (even or odd).
The strings are the keys, the inner dictionaries with the length and parity are the values.

The third file, "question 3.py" is a function that takes in a list of lists of numbers.
It will take the first number in each inner list, and make it to the power of the second number, only if the second number is not negative.
Each of those values will be added to a new list and printed.

The fourth file, "question 4.py" first generates a list of 20 random floats, and an x-value.
Then it will sort the values from smallest to largest, and print that and our x-value.
After that, it will check if any float in the list is the same as our x-value.
Then it will print the index of the first value in our list that matches the x-value, if there is a match.

The fifth file "question 5.py" is a function that takes in the radius of 2 circles.
It will not allow a negative radius, or a radius of 0.
If the numbers entered for the 2 circles are valid, the function will continue and calculate the area of each circle.
Then it will check which circle is larger, and find and return the percentage of the bigger circle that can be covered by the smaller circle.

The sixth, "question 6.py" is a function that takes in a list of numbers.
Then it creates a dictionary where each key is a unique number from the list, and the value is how many times that number appears in the list.
The dictionary is sorted where the keys are smallest to largest before it is returned.

The seventh file, "question 7.py" is a function that will take in an amount of seconds, and convert it into hours, minutes, and seconds, and figure out if it is AM or PM.
If the value entered is negative, the function will ask for a positive number, and exit the function.

The eigth file, "question 8.py" is a function that creates a dataframe the given data.
Then it creates a fourth column, the values of which are calculated by adding up the values of column A, B, and C in each row.
Then the final data frame will be printed.
